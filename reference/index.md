# Package index

## Compute residuals

Compute surrogate response values and surrogate-based residuals for
fitted ordinal and general regression models.

- [`surrogate()`](https://bgreenwell.github.io/sure/reference/surrogate.md)
  : Surrogate response
- [`resids()`](https://bgreenwell.github.io/sure/reference/resids.md) :
  Surrogate residuals
- [`calc_resid()`](https://bgreenwell.github.io/sure/reference/calc_resid.md)
  : Calculate surrogate residuals for multinomial/discrete choice models

## Diagnostics

Simulate p-values from a goodness-of-fit test.

- [`gof()`](https://bgreenwell.github.io/sure/reference/gof.md)
  [`plot(`*`<gof>`*`)`](https://bgreenwell.github.io/sure/reference/gof.md)
  : Goodness-of-Fit Simulation
